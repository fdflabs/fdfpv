# War mode audio: sources and licences

Every audio file of the war mode (docs/WARFARE-PLAN.md section 7) is
listed here with where it came from and under what licence. Paths are
relative to this folder, which `tools/voice/` builds. `npm run
voice:check`, in CI, fails if a file here is missing from this page, if
a file on this page is missing here, or if a file's sha256 is not the
one in `manifest.json`.

This file is part of WebFPVSimulator, licensed GPLv3 or later.

## Voice

Every voice file is generated by `tools/voice/build.py` from the text in
`assets/audio/war/lines.json`. Nobody recorded them and no real person's
voice is cloned: each speaker's voice (lines.json `voices`) is a clip that
Kokoro speaks in a stock synthetic voice, and Chatterbox speaks each of
that speaker's lines in it.

| Part | What it does | Licence | Terms on output |
| --- | --- | --- | --- |
| [Kokoro 82M](https://huggingface.co/hexgrad/Kokoro-82M), revision f3ff3571, stock voices `am_onyx`, `bf_emma`, `bm_george`, `am_michael`, `am_puck` (English) and `em_alex`, `ef_dora`, `em_santa`, `pf_dora`, `pm_alex` (Spanish) | speaks the reference clip | Apache 2.0 | none; the model card says it was trained on permissive and non-copyrighted audio |
| [Chatterbox Multilingual](https://huggingface.co/ResembleAI/chatterbox), revision 5bb1f6ee | speaks every line | MIT | none; every file carries Resemble AI's inaudible Perth watermark, which the package always applies |
| [misaki](https://github.com/hexgrad/misaki) and [espeak-ng](https://github.com/espeak-ng/espeak-ng) | text to phonemes for Kokoro | Apache 2.0, GPLv3 | none |
| [Whisper large v3 turbo](https://huggingface.co/openai/whisper-large-v3-turbo), revision 41f01f3f | listens to each take to reject a bad one; adds nothing to the audio | MIT | none |

The radio sound (band pass, saturation, hiss, key click, squelch, and each
speaker's own colour of it) is `tools/voice/radio.py`, GPLv3 like the rest
of this repository.

The generated files are GPLv3 as part of this repository, the same as
the text they are spoken from.
